# 다크 테마 전환 + 좌측 메뉴 — 작업 계획

밝은 지면은 그대로 두고 검은 지면을 하나 더 만들어 버튼으로 오간다.
메뉴는 위쪽 가로 줄에서 왼쪽 세로 줄로 옮기고, 좁은 화면에서는 햄버거로 접는다.

## 정해진 것

| 항목 | 결정 |
| --- | --- |
| 다크 팔레트 | 옛 다크 퍼플(`#16131f` / `#a56cff`)을 되살리지 않는다. `theme.css`에 이미 있는 `--color-dark-*`(검정 지면 + 금색)를 넓힌다 |
| 좌측 메뉴 | 데스크톱에서는 **항상 펼친 상태**. 접었다 펴는 단추를 두지 않는다 |
| 모바일 | 햄버거로 접는다 |
| 색 처리 | **컨셉 색을 뺀 나머지는 전부 토큰으로 뺀다** |
| 순서 | 1단계 → 2단계 → 3단계 |

옛 퍼플을 버리는 이유는, 지금 연맹 마크·월페이퍼·직업 아이콘이 모두 금색 톤에
맞춰져 있어서다. 보라로 돌아가면 그 에셋들이 지면과 따로 논다.

---

## 지금 상태

- 토큰은 `src/app/theme.css`에 20개. `globals.css`가 옛 이름(`--background` 등)을
  여기에 다시 매핑한다.
- CSS 모듈에 색이 직접 박힌 곳: **서로 다른 색 67개, 등장 101회.**

| 파일 | 하드코딩 |
| --- | --- |
| `equipment.module.css` | 47 |
| `augments.module.css` | 16 |
| `admin.module.css` | 5 |
| `about.module.css` | 11 (대부분 rgba 스크림) |
| `docs` · `vote` · `page` · `reference` · `login` · `classes` | 각 1~5 |

색이 스펙조사 화면에 몰려 있다. 여기를 토큰으로 바꾸지 않으면 다크로 켰을 때
그 화면만 하얗게 남는다.

---

## 1단계 — 색을 토큰으로 정리

화면은 하나도 바뀌지 않는다. 같은 값을 토큰으로 부르게만 바꾼다.
이 단계가 끝나면 다크는 값만 갈아 끼우면 된다.

### 새로 만들 토큰 (15개)

```css
/* 지면 층위 — 위로 갈수록 밝다 */
--color-raised:      #fffefd;  /* 입력칸, 카드 위의 카드 */
--color-panel:       #f8f7f6;  /* 패널 바탕 */
--color-sunken:      #f1efeb;  /* 도구 막대, 홈이 파인 자리 */
--color-inset:       #efede8;  /* 표 안쪽 */

/* 선 */
--color-line-soft:   #e1dcd4;
--color-line-strong: #b9b3ab;

/* 아이템 판 — 아이콘이 얹히는 어두운 자리 */
--color-plate:       #282622;
--color-plate-dim:   #665445;

/* 금색 층위 (--color-accent-tint 보다 아래·위) */
--color-accent-wash: #faf1df;
--color-accent-line: #c5ab7e;
--color-accent-mute: #b59248;
--color-accent-glow: #b6823530;

/* 위험 */
--color-danger:      #b3261e;
--color-danger-deep: #9b201a;
--color-danger-tint: #fff0ed;
```

### 이 토큰들이 흡수하는 값

- **지면** `#fbfaf9` `#f8f7f6` `#fffefd` `#f7f5f0` `#f4f2ef` `#f1efeb` `#efede8`
  `#efebe5` `#eae9e9` `#e7e4df` `#fff` — 비슷한 값이 열한 갈래로 흩어져 있다.
  네 층위로 줄인다.
- **선** `#d9d4cb` `#e1dcd4` `#ded8ce` `#b9b3ab` `#bbb1a0` `#b6a995` `#b0a087`
  와 `rgba(32,31,29,.10~.30)` 여러 갈래
- **어두운 조각** `#282622` `#252423` `#292822` `#302b25` `#665445`
- **금색** `#faf1df` `#fffaf0` `#eae6dd` `#c5ab7e` `#c3a873` `#b59248` `#ffde98`
  `#b6823530` `#b6823522` `#eee7d9aa` `rgba(182,130,53,.45)`
  `rgba(225,173,102,.16/.28)`
- **위험** `#b3261e` `#9b201a` `#fff0ed` `#a22c24` `#a85b50` `#ff8a8a` `#8d492f`

### 컨셉 색 — 손대지 않는다

테마와 무관하게 같아야 하는 값이다. 토큰으로 빼더라도 다크에서 다시 정의하지
않는다.

| 값 | 무엇 |
| --- | --- |
| `#529752` `#5281b5` `#9b75bb` `#c78f48` | 장비 등급 (초록·파랑·보라·금) |
| `#b9abc9` `#d9d3ed80` | 수정 등급 |
| `--color-mark-succession` `--color-mark-awakening` | 계열 마크 (이미 토큰) |
| `rgba(26,25,24,.30~.95)` 6갈래, `#000`, `#37281008` | 월페이퍼 위 스크림 — 사진 위에 얹는 것이라 지면 색과 무관 |

스크림은 이미 `--scrim-band` `--scrim-dark-hero`가 있으니 나머지도 그 옆에 모은다.

### 순서

1. `theme.css`에 위 15개 추가
2. `equipment.module.css` → `augments.module.css` → `admin.module.css` 순으로 치환
   (많은 것부터. 여기만 끝나면 68/101이 정리된다)
3. 나머지 파일 정리
4. 화면별로 눈으로 대조 — 값이 같으니 달라 보이면 잘못 묶은 것이다

**검증** — 치환 전후로 각 화면을 같은 크기에서 찍어 비교한다. 1단계는 "아무것도
안 바뀌는 것"이 성공 조건이다.

## 2단계 — 다크 팔레트 + 전환 버튼

### 팔레트

`theme.css`에 `:root[data-theme="dark"]` 블록을 만들고 1단계에서 만든 토큰을
다시 정의한다. 뼈대는 이미 있는 다크 토큰이다.

```
--color-paper   #1a1918   (지금 --color-dark)
--color-surface #252423
--color-ink     #f3f2f2   (지금 --color-dark-ink)
--color-ink-dim #bab6b6   (지금 --color-dark-ink-dim)
--color-accent  #e1ad66   (지금 --color-dark-accent)
```

지면 층위는 밝은 쪽과 방향이 뒤집힌다 — 밝은 테마에서 `raised`가 가장 밝다면
다크에서는 `raised`가 가장 옅게 밝다. 아이템 판(`--color-plate`)은 반대로
밝아져야 아이콘이 묻히지 않는다.

### 전환

- `<html data-theme="dark">`로 켠다. `localStorage`에 기억한다.
- 아무것도 고르지 않은 사람은 `prefers-color-scheme`을 따른다.
- **첫 페인트 전에 도는 인라인 스크립트**가 필요하다. 없으면 새로고침할 때마다
  흰 화면이 한 번 번쩍인다. `layout.tsx`의 `<head>`에 넣는다.
- 단추는 헤더(3단계 뒤에는 좌측 메뉴 아래)에 둔다.

### 살펴야 할 곳

- 로그인 화면은 이미 어두운 스크림 위에 얹혀 있다. 다크에서 두 번 어두워지지
  않는지 본다.
- 히어로 밴드는 원래 어둡다. 다크 지면과 경계가 사라지지 않게 선을 남긴다.
- 장비 아이콘은 어두운 판 위에 그려진다. 다크에서 판이 밝아지면 아이콘 테두리를
  다시 본다.
- 디스코드 링크 미리보기(`og.jpg`)와 `themeColor`는 밝은 쪽 기준으로 두고
  바꾸지 않는다.

## 3단계 — 좌측 메뉴 + 모바일 햄버거

가장 크게 구조를 건드린다.

### 지금 구조

페이지마다 `<main className={styles.main}>` 안에 `<SiteHeader>`가 가로로 들어 있다.
`main`의 최대 폭과 좌우 여백을 페이지가 각자 갖고 있다.

### 바꿀 구조

공통 셸을 만들어 `[사이드바][본문]` 두 칸으로 나눈다. 페이지는 본문만 그린다.

- **데스크톱** — 사이드바 항상 펼침. 접는 단추 없음.
  목업 `1b 홈 · 원장형`의 "좌측 색인 레일"이 그 모양이다
  (`docs/design_handoff_union_ledger/아시바당 Site Mockups.dc.html`).
- **모바일** — 햄버거로 열고 닫는다. 열렸을 때 바깥을 누르거나 Esc로 닫힌다.
  포커스가 서랍 밖으로 새지 않게 잡는다.

### 사이드바에 들어갈 것

지금 헤더에 있는 것 그대로다.

- 마크 + 아시바당 (홈 링크)
- 홈 · 투표 · 직업 등록 · 스펙조사 · 연맹 소개 · 문서 (+ 관리자)
- 프로필 사진 + 닉네임
- 로그아웃
- **테마 전환 단추** (2단계에서 만든 것)

### 손대야 할 파일

`layout.tsx`, `SiteHeader.tsx`(→ 사이드바로), 그리고 8개 페이지의 바깥 틀 —
`/`, `/vote`, `/classes`, `/equipment`, `/about`, `/docs`, `/admin`, `/login`.

`/login`은 사이드바 없이 두는 편이 낫다. 로그인 전에는 갈 곳이 없다.

### 살펴야 할 곳

- `/vote`는 디스코드 링크로 바로 들어오는 화면이다. 첫 화면에서 투표 단추가
  접히지 않는지 본다.
- `/equipment`와 `/admin`은 본문이 넓다. 사이드바 폭만큼 좁아져도 표와 판이
  들어가는지 본다.
- 지금 헤더의 `order`와 `flex-wrap`으로 맞춰 둔 모바일 배치는 통째로 사라진다.

---

## 한 번에 하지 않는 이유

1단계는 눈에 보이는 변화가 없어 답답하지만, 건너뛰면 다크에서 스펙조사 화면이
하얗게 남는다. 2단계까지 끝내면 그 자체로 쓸 수 있는 기능이고, 3단계는 되돌리기가
가장 어려우므로 마지막에 둔다.

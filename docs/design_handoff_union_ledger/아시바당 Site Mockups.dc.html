투표 사용법

거점전 설문은 매주 목요일 시작 15분 전에 디스코드로 링크가 전송됩니다. 링크를 열면 디스코드 계정으로 로그인되고, 연맹에 등록된 계정만 투표 화면에 들어갈 수 있습니다.

1. 표 종류

참여본대 참가. 직업 등록 필수.
부속대기 인원. 참여로 전환해도 순번이 유지됩니다.
늦참시작 이후 합류. 별도 명단으로 집계됩니다.
미참불참. 사유 입력은 필요하지 않습니다.

2. 중복 투표

같은 설문에 다시 투표하면 이전 표가 갱신됩니다. 마감 이후에는 버튼이 비활성화되며, 변경이 필요한 경우 지휘부에 직접 요청하세요.

참고

150명이 동시에 투표해도 문제가 없도록 투표 UI는 웹으로 분리되어 있습니다. 봇은 알림과 운영 명령어만 담당합니다.

3. 마감 시각

기본 마감은 거점전 시작 30분 전입니다. 공휴일이나 임시 일정은 공지 채널에 별도 안내됩니다.
